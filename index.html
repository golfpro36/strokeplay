เจ้าหน้าที่ประจำก๊วนกรอกคะแนนทีละหลุมจากมือถือ ผลขึ้นจอทันที — Gross, Net (แต้มที่แจ้ง / System 36), เทียบการ์ดตาม R&A, กรรมการตรวจและล็อกผลทางการ

ขั้นตอนใช้งาน
  1. กรรมการเข้า "กรรมการ" → วางรายชื่อจาก Excel (ชื่อ เพศ HCP รุ่น ก๊วน เวลาออก หลุมออก)
  2. พิมพ์ "บัตรก๊วน" (QR + รหัส 4 หลัก) แจกเจ้าหน้าที่ประจำก๊วน หรือผู้เล่นที่เป็น Marker
  3. สแกน QR → กรอกคะแนนทีละหลุม (สัญญาณหายก็กรอกต่อได้ ส่งเองเมื่อกลับมาออนไลน์)
  4. จบรอบ ผู้เล่นยืนยันการ์ด → ส่งการ์ด → กรรมการตรวจ → ล็อกรอบ = ผลทางการ
