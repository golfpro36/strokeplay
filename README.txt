GolfPro Stroke Play — หน้าเว็บสำหรับ GitHub Pages (repo แนะนำ: golfpro36/strokeplay)
1) อัปโหลดทุกไฟล์ในนี้ขึ้น repository (ไฟล์อยู่ชั้นเดียว ไม่มีโฟลเดอร์ย่อย)
2) แก้ config.js บรรทัดเดียว: ใส่ลิงก์ Web App ของ Apps Script (ลงท้ายด้วย /exec)
3) Settings → Pages → Deploy from a branch → main / (root) → Save
หน้าแรก: index.html   หน้างาน: event.html?event=รหัสงาน
ห้ามอัปโหลด Code.gs หรือไฟล์ใน 1_AppsScript ขึ้น GitHub (repo เป็นสาธารณะ)
